**task_a — 메모 저장·다시 열기**

대상은 Memo demo build A, desktop Chrome입니다. 아래는 합성 시나리오 작성자의 전달 기록 요약이며, 실제 제품 실행·독립 재현 결과가 아닙니다. 새 실행·수정·캡처는 하지 않았습니다(`screenshots=off`).

| 목표 / 기대 근거 | 전달 기록의 행동·결과 / 판정 | 근거 |
|---|---|---|
| 저장한 본문이 다음 방문에도 유지됨 — 제품 도움말의 명시적 약속 | 빈 계정에서 `sample / alpha` 입력 → Save → Saved 토스트와 본문 표시 → 새로고침 → `sample`을 열면 본문이 비어 있음. **기록상 저장·다시 열기 목표 실패, 실제 제품에서는 미검증** | A1–A3 |
| 다른 메모로 같은 순서 반복 | `sample2 / beta`에서도 Saved 표시 후 새로고침하면 본문이 비어 있음 | A4 |

저장 성공 표시와 다시 열린 본문이 불일치합니다. 실제로 발생한다면 입력 내용을 다시 사용할 수 없는 기능 문제입니다. 토스트 표시만으로 저장 성공을 판정할 수 없으며, 합성 기록의 두 사례를 실제품 재현 빈도로 해석할 수 없습니다. 원인·실제 데이터 소실 여부는 서버·코드·네트워크 근거가 없어 미확인입니다.

남은 확인은 실제 빌드에서 같은 두 입력을 저장하고 새로고침·다시 열기 후 본문을 비교하는 것입니다. 빈 본문이 저장 실패인지 조회·표시 문제인지도 확인해야 합니다. 이번에는 수행하지 않았습니다.

**task_b — 첫 사용자·재방문·숙련 관점 비교**

대상은 Game demo build G이며, 전달 기록은 같은 데스크톱·키보드를 전제로 합니다. 이 역시 합성 자료이므로 **실제 실행이 입증된 시도는 없습니다.** 다음은 기록이 묘사하는 시도와 그 한계를 구분한 비교입니다. 새 실행은 하지 않았습니다.

| 시도 / 관점 | 지식·도움과 경계 | 기록이 묘사하는 도달 단계 | 판정·남은 근거 |
|---|---|---|---|
| R1 / 첫 사용자 L0 관점 | 중립 목표와 초기 게임 상태. 컨텍스트 분리 증거가 없어 `unverified` | 화면에서 조작을 찾다가 종료. 플레이 입력·라운드 결과 미도달 | 목표 미완료(B1). 독립적인 사전 지식 없는 사용자 시험으로 인증할 수 없음 |
| R2 / R1에 연결된 도움받은 시도 | 외부 진행자가 Space 시작 방법 제공. `informed`; 소스·PRD 미제공만으로 격리가 증명되지는 않음 | Space → 플레이 입력 → 라운드 결과 → 재시작 화면 | 기록상 한 라운드 완료(B2). 재시작 실행 성공은 미확인. 자력 시작 방법 발견의 성공으로 세면 안 됨 |
| R3 / 재방문 L1 관점 | R2에서 배운 Space 사용. 외부 제공 지식과 기록상 사용 경험을 이어받음 | 같은 게임 상태에서 라운드 완료·재시작 성공 | 기록상 익숙한 경로 재사용 성공(B3). 독립된 새 사용자 표본이 아님 |
| L2 / 숙련 관점 | 관련 숙련도를 뒷받침할 근거 없음 | 별도 시도 없음 | **미실행(`not-run`)**. 고급 조합·전략 선택·다른 상황으로의 전이 기록이 없어 R3를 L2로 승격할 수 없음 |

기록상 차이는 R1의 시작 방법 탐색 중단, 외부 힌트 후 R2의 라운드 완료, R3의 학습한 경로 재사용입니다. Space 지식의 최초 출처는 **외부 제공**, 이후 사용 경험은 **기록상 관찰**로 구분해야 합니다. R2·R3의 성공이 R1의 미완료를 지우지는 않습니다.

이는 연결된 학습 순서이지 독립적인 세 집단 비교가 아닙니다. 첫 진입 안내의 발견 가능성을 추가 확인할 단서는 있지만, 화면 증거와 독립 실행 없이 확정 UI 결함이나 숙련도의 인과 효과로 결론 낼 수 없습니다. R2의 초기화 상태·도구/컨텍스트 격리, 실제 이미지·시간측정·독립 사용자 표본도 없습니다. 사람의 성공률·소요 시간·만족도·게임 난이도는 산출할 수 없습니다.
