# 로컬 메모 앱 경험 수준 비교 QA

**실제 UI 검증은 환경 제약으로 시작하지 못했습니다.** 제품 결함 0건이라는 평가나 통과 판정을 하지 않습니다. L0는 제품 화면 도달 전 `blocked`, L1·L2는 `not-run`으로 구분해 보존했습니다.

## 범위와 실행 조건

- 대상: `http://127.0.0.1:8765/notes.html`; 제품 빌드 식별자 미확인.
- 요청: `profile=compare`, `screenshots=on`, 한국어 보고서. 로컬의 폐기 가능한 메모 생성·편집 권한이 있었지만 실제 데이터 변경은 없었습니다.
- 목표: 제목 **첫 메모**, 본문 **내일 우유 사기** 작성·저장·재열기 → 복귀 편집 → 여러 메모를 이용한 반복 작업.
- 완료 기준: 실제 UI에서 저장한 값을 재열어 비교. 화면 방문이나 성공 메시지만으로 완료하지 않음.
- 실행자: AI 도구 실행. 실제 사람 참여, 대표 사용자 연구, 사람의 속도·만족도 평가는 아닙니다.
- 계획한 비교: 동일 AI의 순차 학습. 독립 사용자 비교가 아니며, 이번에는 학습 순서 자체가 시작되지 않았습니다.

## 결과 비교

| 기록 / 프로필 | 시작 지식·상태 | 실행 결과 | 완료한 제품 목표 | 경험 근거 |
|---|---|---|---|---|
| [L0-01.json](L0-01.json) / L0 | 중립 목표·진입점만 제공; 제품 상태 미확인 | `blocked`: UI 도달 전 브라우저/연결 제약 | 없음 | `none`, 경계 `unverified` |
| [L1-01.json](L1-01.json) / L1 | 가져올 제품 사용 학습 없음 | `not-run` | 없음 | 이전 사용을 만들지 않음 |
| [L2-01.json](L2-01.json) / L2 | 관련 핵심 작업 숙련 근거 없음 | `not-run` | 없음 | 반복 사용/숙련을 만들지 않음 |

기능 결과와 경험 수준의 유효성은 별개입니다. 제품 UI를 관찰하지 못했으므로 기능 `failed`나 `passed`로 분류할 근거가 없습니다. L1·L2 파일은 미실행 기록이며 실제 경험 시도나 참여자 수에 넣을 수 없습니다.

## 관찰한 환경 제약

1. 설치된 Python Playwright와 Chromium으로 브라우저를 시작하려 했지만, 제품 화면을 열기 전 `socket() failed: Operation not permitted (1)`로 종료됐습니다.
2. 별도 클라우드 브라우저로 지정 URL을 열었으나 `net::ERR_CONNECTION_REFUSED`였습니다. 이 브라우저가 로컬 fixture에 도달했다는 증거는 없습니다.
3. 기본 실행 환경에서 AF_UNIX 소켓 생성은 `EPERM`, AF_INET 소켓 생성은 가능했습니다. 지정 localhost 포트로의 TCP 연결은 `ECONNREFUSED`였습니다.
4. 부모도 같은 Chromium 시작 오류를 확인한 뒤 추가 우회·권한 상승 없이 중단하도록 지시했습니다. 클라우드 브라우저 작업의 완료 요약도 제출했습니다.

이 결과는 해당 도구 환경에서의 접근 실패를 보여 줍니다. 제품 자체 오류, 저장 실패, 전체 서버 장애, 봇 차단 또는 제품의 정상 동작을 입증하지 않습니다. 추가적인 원인 진단은 하지 않았습니다. 전체 브라우저 실행 인자·프로필 경로·불필요한 오류 덤프는 보관하지 않았습니다.

증거: [setup.json](setup.json), [setup-actions.jsonl](setup-actions.jsonl), [environment.json](environment.json). `setup-actions`는 제품 클릭 기록이 아니라 도구 준비 및 연결 검사입니다.

## 학습·스크린샷·남은 검증

- 제품 소스, fixture 파일, 기존 보고서, 평가 rubric은 읽지 않았습니다. QA 절차와 템플릿은 읽었습니다. 실제 전체 컨텍스트 격리를 독립 검증하지 못했으므로 cold 경계는 `unverified`로 기록했습니다.
- 관찰한 제품 지식, 제품 내 도움, 외부 해결 경로 힌트, 저장 메모, 편집 결과가 없습니다. 학습 내용을 다음 수준으로 가져오지 않았습니다.
- 스크린샷은 **ON**이었으나 제품 화면에 도달하지 못해 파일을 생성하지 않았습니다. 캡처 커버리지는 L0 `unavailable`, L1·L2 `not-run`입니다. 시각 검토가 된 이미지로 주장할 증거가 없습니다.
- 실제 뷰포트·브라우저 버전·제품 상태는 미확인입니다. 1280×900은 실행 계획일 뿐 검증 환경의 실측값이 아닙니다.
- 기능, 사용성·접근성, 수명주기, 제품 오류 복구, 데이터 무결성, 제품 호환성·성능은 모두 미검증입니다. 배포·운영 준비 평가는 이번 범위에 해당하지 않습니다.
- 후속 실행에서는 제품에 도달하는 허용된 UI 환경을 먼저 확보하고, 새 L0 기록으로 원래 목표를 시작해야 합니다. L1은 실제 L0의 사용자에게 보이는 학습만, L2는 완료한 핵심 작업과 여러 메커니즘의 관찰 근거가 있을 때만 진행해야 합니다.

제품·스킬 수정과 외부 게시를 하지 않았습니다. 이 산출물은 검증 한계와 미실행 범위를 보존한 QA 기록입니다.
